Wordmark PNGs: 2400 pixels wide, transparent background.
Mark and icon PNGs: 1024 x 1024.
SVG wordmarks use outlined lettering and do not require fonts.

Palette: #FF6A13 safety orange / #20251E ink / #F8F7F2 warm paper.
Preserve proportions. Keep one bar-width of clear space around the mark.
Use the symbol alone below a 120-pixel wordmark width.

Original vector artwork; PNGs rendered with Sharp. No image-generation API used.
